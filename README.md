# Tattersall — Early Vertical Agent Prototype

This repository is an **original May 2025 experiment** from the earliest stage of the N3uralia engineering history.

It explored a simple question that later became central to the portfolio:

> What changes when AI agents are designed around a real business domain instead of as generic chatbots?

The prototype used e-commerce as the test environment and separated responsibilities such as customer support, sales, inventory, shopping assistance and marketing into specialized agent roles.

---

## Why this repository matters

Tattersall is not a current N3uralia product. Its value is historical.

It records an early move from a single AI assistant toward a **domain-specific multi-agent operating model**:

```text
Business domain
      ↓
Specialized responsibilities
      ↓
Agent roles
      ↓
Tools / APIs / shared context
      ↓
Operational actions
```

Several ideas explored here later became much more rigorous across N3uralia systems:

- specialized agents instead of one universal assistant;
- explicit business responsibilities;
- tool and API access tied to those responsibilities;
- shared operational context;
- human-visible actions and outcomes;
- AI embedded inside a domain workflow rather than added as a standalone chat layer.
